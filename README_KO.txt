후쿠오카·유후인 여행 일정 | 웹서버 업로드용

이 압축파일은 사이트에 게시한 결과가 아니라, 게시에 필요한 파일 묶음입니다.
기존 일정·예약 방법·지도·네이버 링크는 유지하고, 5개 날짜의 상단에 기존 생성 지도 이미지를 추가했습니다.

[구성]
fukuoka-trip/
  index.html         여행 일정 웹페이지
  share-preview.jpg 카카오톡 등의 링크 미리보기용 대표 이미지
  assets/
    day-1.webp ~ day-5.webp  날짜별 지도 이미지
  README_KO.txt      이 안내

[업로드]
1. 사용할 웹서버의 정적 파일 공개 폴더 아래에 새 여행 폴더를 만드세요.
   기존 사이트의 index.html을 덮어쓰지 말고 별도 폴더를 사용하세요.
2. 위 구조를 유지하여 폴더 내용을 업로드하세요.
   index.html과 assets 폴더를 함께 올려야 본문 이미지가 보입니다.
3. index.html의 다음 예시 문자열을 모두 실제 배포 폴더의 HTTPS 주소로 바꾸세요.
   https://YOUR-DOMAIN.example/trip/fukuoka-2026/
   이 문자열은 og:url 및 og:image에 있습니다. 끝의 /를 유지하세요.
4. 휴대폰에서 실제 배포 주소를 열고 5개 날짜의 이미지와 확대 버튼을 확인하세요.
5. 확인한 HTTPS 주소를 카카오톡 채팅방에 보내세요.
   이 대화의 sandbox 다운로드 주소는 공개 배포 주소가 아닙니다.

[미리보기와 본문은 다릅니다]
- 본문 지도: 사이트를 연 뒤 각 날짜 상단에서 보는 5장입니다.
- 링크 미리보기: 채팅방의 링크 카드에 쓰는 대표 이미지입니다.
- og:image에는 카카오 서버가 접근 가능한 이미지의 절대 HTTPS 주소를 사용하세요.
- data:image/...를 og:image에 넣는 방식에 의존하지 마세요.
- 미리보기는 카카오의 수집·캐시·앱 환경에 따라 달라질 수 있습니다.
- 웹페이지가 로그인으로 보호되어 있으면 미리보기를 수집하지 못할 수 있습니다.

[개인정보]
숙소 상세주소와 여행 날짜가 포함되어 있습니다. 일행에게만 공유하세요.
검색 제외용 robots 메타 태그를 넣었지만 접근 권한을 제한하는 장치는 아닙니다.
비공개가 필요하면 서버에서 접근 제한을 설정하고, 그 경우 미리보기가 나오지 않을 수 있음을 고려하세요.

[별도 이미지 없이 파일 하나만 보관]
별도로 제공된 fukuoka_yufuin_trip_with_maps.html에는 지도 5장이 Base64로 내장되어 있습니다.
파일 하나를 브라우저로 열면 일정과 이미지가 나타납니다.
카카오톡 첨부파일을 여는 앱은 휴대폰 환경에 따라 다를 수 있으므로,
여행 일행의 휴대폰 열람에는 위의 HTTPS 주소 공유를 권합니다.

[지도 일러스트]
그림은 실제 지형을 재현한 내비게이션 지도가 아닙니다.
실제 위치·거리·이동수단·시각은 본문의 일정과 지도 링크를 기준으로 확인하세요.
원본 이미지를 다시 그리거나 내용을 바꾸지 않고, 해상도를 유지한 WebP 형식으로 최적화했습니다.
